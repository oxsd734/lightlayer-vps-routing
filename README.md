## 几个真实疑问

**能装 Windows 吗？**
LITE 官方标注仅支持 Linux。SSD 款的系统模板清单现有信息没有覆盖，下单前用客服确认最稳。

**流量用超了会怎样？**
LITE 支持额外购买流量包。具体超量计费方式以订购页和客服说明为准，别按"会自动限速"假设。

**联通用户能用吗？**
能用，延迟偏高、晚高峰可能抖。用来做后台管理、偶尔登录操作没问题；拿来服务联通为主的访客，体验会有落差。

**以后能升配置吗？**
支持配置升级，LITE 最高可到 2 核 2GB。升级通常涉及补差价和重启，具体规则下单前问清楚。

**有优惠码吗？**
这款机型一般不支持优惠码，官方折扣体现在季付 5%、半年付/年付 17% 的周期优惠上。市面上流传的所谓 Lightlayer 优惠码多为独服活动，别套用到云机上。
